summary: "Understanding an unfamiliar codebase can mean jumping between files
  just to answer one question. RepoMentor is a local RAG assistant I built to
  make that easier. It combines semantic and keyword search to find relevant
  code, then generates an explanation with source-code citations so you can
  check the evidence yourself. If the retrieved code doesn’t provide enough
  support, it acknowledges that instead of filling in the gaps. The pipeline
  processed 188 repository files into 324 searchable chunks. The goal is simple:
  spend less time hunting through files and get a clearer starting point for
  understanding how the code works."
